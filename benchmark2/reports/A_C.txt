DEFECT 9

where: ul.file-list[aria-live="polite"] (no aria-atomic / aria-relevant), containing all rows plus the per-file percentage text
repro: Read the live-region attributes on the rendered list (aria-live="polite", aria-atomic null, aria-relevant null), then attached a MutationObserver to ul.file-list and clicked Upload: 123 mutations over ~2.5s, with each row's status text changing 0% -> 12% -> 38% -> 73% -> 98% -> Done and the li nodes being replaced rather than updated in place.
severity: minor
category: a11y

DEFECT 10
what: A file dropped anywhere on the page outside the dashed zone is not intercepted, so the browser handles it itself and navigates away from the widget, discarding the list of files already selected.
where: document/body — no dragover/drop handler; only .drop-zone calls preventDefault
repro: Dispatched dragover and drop carrying a file on document.body and inspected the events: defaultPrevented was false for both (and the list was unchanged), whereas the same events on .drop-zone come back with defaultPrevented true. With the page-level default left in place the browser opens the dropped file in the tab, replacing the page and its selection.
severity: minor
category: logic
